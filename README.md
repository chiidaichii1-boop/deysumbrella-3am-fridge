One line a smart fridge texts its owner at 3am — entered in the make.fun bounty [The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d).

## Run

```sh
python3 main.py
```

The program writes a single 123-character line to `entry.txt` in the output
directory (`MAKEFUN_OUTPUT_DIR`, falling back to `/output`).

## Entry

> 3am. You keep staring into my light like it holds answers. It holds leftovers and one yogurt you will never eat. Go to bed.
